在另一台电脑安装导出的驱动
假设驱动文件夹在 D:\EPSON_Backup。
1. 右键开始菜单，打开「终端（管理员）」。
2. 执行：
pnputil /add-driver "D:\EPSON_Backup\*.inf" /subdirs /install


3. 等待安装完成。
4. 打开「设置」→「蓝牙和其他设备」→「打印机和扫描仪」。
5. 添加 EPSON LQ-630K 打印机。
如果 Windows 没有自动识别，可以在手动选择驱动时指定 EPSON LQ-630K ESC/P2。
